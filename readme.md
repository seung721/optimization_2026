업체 CSV (A, B, H, I, L)

Price = 할인 전 판매가격
Capa = 최대 공급 가능 수량
Demand = 총 수요 (모든 업체 동일)
DVT = 물량 구간별 할인율 테이블

영업회신 파일

모델별로 몇 개 업체 선정하는지
선정된 업체들한테 물량 몇 % 나눠주는지
우리가 몇 대 받고싶은지 (TargetVolume)

Tier 파일
